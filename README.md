# ANIMA Compiler

給 ComfyUI（Anima 底模）用的「中文畫面描述 → 英文正向提示詞」編譯規格。

本倉庫存放的是**規格、角色資料與驗收案例**；實際編譯由 GPT-5.6 或 Sonnet 5 依這份規格執行，倉庫內只有維護用的檢查腳本，沒有執行時程式。圖片由使用者在自己的 ComfyUI 生成。

## 從哪裡開始

| 想做什麼 | 看哪份 |
|---|---|
| 部署到 GPT / Claude 專案 | `使用說明.md` |
| 這版改了什麼 | `本次修訂說明.md` |
| 編譯行為規則 D01–D08 | `directing.md` |
| 角色映射、身份限制、年齡線索 | `characters.json` |
| prefix / rating / 固定負向契約與工作流快照 | `pipeline.json` |
| 實測證據與各條的適用邊界 | `observations.md` |
| 80 個待測案例與冒煙順序 | `驗收/模型測試案例.json` |

部署時只需要 `00_<平台>_系統提示.md`（貼進專案指示）加上 `directing.md`、`characters.json`、`pipeline.json` 三份附件。

## 維護

`00_*_系統提示.md` 與 `驗收/模型驗收案例.md` 是**衍生檔，不要手改**。
入口來源是 `維護資料/入口共用規則.md` 加上對應的 `維護資料/<平台>適配.md`；案例來源是 `驗收/模型測試案例.json`。

改完來源後：

```bash
node 維護資料/重建與檢查.cjs          # 重建衍生檔並執行檢查
node 維護資料/重建與檢查.cjs --check  # 只檢查，不重建
```

來源清單（`維護資料/v025_source_manifest.json`）不會自動更新，需人工審核變更後更新雜湊——這是刻意的，避免把意外修改自動認可。完整流程見 `使用說明.md` 的「維護」段。

## 狀態

靜態檢查通過（結構、資料保留、衍生檔同步）。

**兩個目標模型均未實跑**（`NOT_RUN`），成圖效果亦未驗證。靜態通過不等於模型會遵守規則，也不代表出圖品質。
